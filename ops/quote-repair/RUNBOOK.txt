Installer inquiry repair - 2026-11-02

Scope
The public form saves a receipt before dispatch. Missing CAPTCHA configuration
or a CAPTCHA provider outage holds the request for staff review. Invalid tokens,
reserved test addresses and injection-shaped identity fields are rejected.
Legacy /webhook/rfq/submit accepts bounded, idempotent review records only: it
does not send SMS, create a customer support ticket or notify installers.
Historical rows are preserved. Probe-like records 19-26, 29 and 30 are quarantined.
Other historical rows are held. Never replay old notifications automatically.

Production configuration (root-only, never commit keys)
/root/vicrez-ai-agent/data/quote-safety.json:
  dispatch_enabled: boolean; false is the emergency pause.
  sitekey and secret: existing Vicrez Cloudflare Turnstile widget credentials.
  provider: "turnstile" (required; other or absent providers stay in review mode).
The registered hostname must include installers.vicrez.com. Test sitekeys are
rejected. The browser sees only sitekey and mode; the secret stays on the server.
With dispatch_enabled=true and no keys, new requests still require staff review.
The browser loads challenges.cloudflare.com/turnstile/v0/api.js. The server
validates through Cloudflare Siteverify and requires hostname installers.vicrez.com
and action installer_quote. Turnstile tokens expire after five minutes and are
single-use. Production rejects Cloudflare dummy sitekeys and secret keys.
Widget management requires Account:Turnstile:Edit. Use an installers-only widget,
managed mode, domain installers.vicrez.com, and no clearance cookie. Do not change
DNS, WAF, zone security levels, or other widgets as part of this setup.
Authenticated staff can release a current request after documenting the real
project, customer permission and recipient scope. Legacy requests require a new
form because the historical path did not record the current sharing consent.
